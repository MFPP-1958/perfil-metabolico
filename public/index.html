Esta integración puede recibir más elementos de Intervals.icu, pero el dashboard solo mostrará los IDs que indiques como ciclistas entrenados. La clave API y el filtro de IDs se guardan solo en este navegador mediante almacenamiento local.

Datos importables

Qué intenta importar esta versión

  • Lista de atletas vinculados a tu cuenta de entrenador.
  • Selección directa del ciclista desde un desplegable.
  • Botón único para cargar el análisis metabólico del atleta seleccionado.
  • Nombre del ciclista.
  • Peso, si está disponible.
  • FTP/eFTP/mFTP, si está disponible.
  • Mejores potencias aproximadas desde actividades recientes cuando la API las devuelve.
  • Actividades recientes para revisar volumen, desnivel y carga.

La disponibilidad exacta depende de los permisos del atleta, de los campos que devuelva Intervals.icu y de posibles restricciones CORS del navegador.

Nota técnica para uso profesional

Versión directa desde navegador: cómoda para uso personal, pero la API Key queda en el propio navegador del entrenador.

Versión profesional recomendada: crear un pequeño servidor intermedio privado. Así la API Key no viaja dentro del archivo HTML y se pueden gestionar varios ciclistas con más seguridad.
