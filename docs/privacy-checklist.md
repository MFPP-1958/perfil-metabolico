# Lista de privacidad y protección de datos

Esta lista debe cerrarse con el responsable del tratamiento y asesoramiento jurídico antes de usar datos reales en producción.

## Finalidad y minimización

- [ ] Documentar responsable, encargados, finalidad, base jurídica y plazo por cada categoría de datos.
- [ ] Guardar banda de edad en lugar de fecha de nacimiento cuando sea suficiente.
- [ ] Mantener bienestar desactivado hasta justificar necesidad y finalidad.
- [ ] No importar ubicaciones, notas privadas ni salud si el análisis no las necesita.
- [ ] Definir quién puede ver, exportar, rectificar y borrar cada registro.

## Menores y datos de salud

- [ ] Verificar consentimiento o base aplicable y la información entregada a representantes legales.
- [ ] Evitar etiquetas permanentes de talento, fenotipo o especialidad.
- [ ] Evaluar si procede una evaluación de impacto por perfilado, menores o datos de salud.
- [ ] Separar apoyo al entrenamiento de cualquier diagnóstico médico.

## Seguridad y derechos

- [ ] MFA para la cuenta administradora y revisión trimestral de accesos.
- [ ] RLS verificada con dos identidades reales en preproducción.
- [ ] Contratos de encargado y región de tratamiento revisados para Supabase, Netlify e Intervals.icu.
- [ ] Canal y procedimiento para acceso, portabilidad, rectificación, oposición y supresión.
- [ ] Retención, restauración, eliminación e incidentes ensayados y fechados.

Referencias de trabajo: Reglamento (UE) 2016/679, LOPDGDD y guías de la [Agencia Española de Protección de Datos](https://www.aepd.es/).
